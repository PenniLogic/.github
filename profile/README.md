# PenniLogic

Debt-first personal finance software, built in public.

| Repository | Scope |
| --- | --- |
| [docs](https://github.com/PenniLogic/docs) | Product, architecture and delivery backlog |
| [contracts](https://github.com/PenniLogic/contracts) | Shared API contracts |
| [api](https://github.com/PenniLogic/api) | Kotlin/Ktor backend; current health scaffold |
| [ai-service](https://github.com/PenniLogic/ai-service) | Planned backend AI routing |
| [android](https://github.com/PenniLogic/android) | Planned Kotlin/Compose client |
| [web](https://github.com/PenniLogic/web) | Planned customer web application |
| [admin](https://github.com/PenniLogic/admin) | Planned isolated operator console |
| [infra](https://github.com/PenniLogic/infra) | Local infrastructure and public repository setup |

Standard GitHub-hosted CI, one GitHub owner, and separate AI implementation/review
sessions. Repository setup is not a completed product or financial/compliance
release approval. See the [migration record](https://github.com/PenniLogic/docs/blob/main/MIGRATION.md).
